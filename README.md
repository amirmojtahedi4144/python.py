## 🚀 شروع سریع

### پیش‌نیازها

- [Python 3.10+](https://www.python.org/downloads/)
- pip

### نصب

```bash
# کلون کردن ریپازیتوری
git clone https://github.com/username/repo.git

# ورود به پوشه پروژه
cd repo

# نصب پکیج‌های موردنیاز
pip install -r requirements.txt
```

### اجرا

```bash
python python.py
```
